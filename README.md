# Web Scraping Alura

Notebook de estudos sobre **Web Scraping** em Python (baseado no treinamento da Alura), utilizando `BeautifulSoup`, `urllib` e `pandas` para coleta e tratamento de dados da web.

## Tecnologias utilizadas

- Python 3
- [BeautifulSoup4](https://www.crummy.com/software/BeautifulSoup/) (`bs4`)
- `urllib.request`
- [pandas](https://pandas.pydata.org/)
- Jupyter Notebook

## Como executar

1. Instale as dependências:
   ```bash
   pip install beautifulsoup4 pandas notebook
   ```

2. Inicie o Jupyter Notebook (no Windows, também é possível usar o script `Start Jupyter.bat`):
   ```bash
   jupyter notebook "Web Scraping.ipynb"
   ```
